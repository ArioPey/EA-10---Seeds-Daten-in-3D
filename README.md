# Seeds Daten in 3D

Seeds-Datensatz (UCI) mit t-SNE (tSNEJS) auf 3 Dimensionen reduziert und in WebGL dargestellt.
Statische Seite ohne Build-Schritt.

Lokal testen:  `python3 -m http.server`  und dann http://localhost:8000 öffnen.
Parameter neu suchen:  `node tools/optimize.js`  (überschreibt data/seeds_tsne3d.csv)
GitHub Pages: Settings > Pages > Branch `main`, Ordner `/ (root)`.
